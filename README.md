# 巷口清單 · home_nearby_food

本地預覽網站：以板橋新埔生活圈為中心，整理 Google 步行 20 分鐘內或開車 15 分鐘內的 575 家店。

## 預覽

這是純 HTML、CSS、JavaScript 網頁，不需要安裝套件。可以直接開啟 `index.html`，或使用 Python 靜態伺服器：

```sh
python3 -m http.server 8765 --bind 127.0.0.1
```

瀏覽 `http://127.0.0.1:8765`。店家照片和字型需要網路；照片失效時會顯示提示與 Google Maps 原始頁面入口。

## 功能

- 餐點搜尋、Google 評分／評論數／距離／價格排序。
- 料理國別、餐廳型態、適合時段、場合、兒童友善交叉篩選。
- 七種人均價帶；估算價格範圍與價帶有交集就列入，可能落在多個價帶。
- 每店五張 Google Maps 頁面照片、放大相簿、資料來源與步行／開車導航。
- 每次載入 24 間卡片，搜尋與篩選涵蓋全部 575 間。
- 本機收藏，儲存在瀏覽器 localStorage；沒有登入或外部資料庫。

## 資料與限制

資料查閱日期為 **2026-10-04**。評分、評論數與店址直接讀取 Google Maps 店家頁面；步行與開車距離和時間直接讀取 Maps 路線，以住家所在社區起點出發，未計出電梯、停車、停車後步行、候餐與排隊時間。不是現場測量或即時營業保證。575 家是不重複候選名單，並非附近全店普查。

人均為估算預算，依公開食記、菜單或外送價格整理；新補店家部分預算為依定位與公開照片／評論推估，尚未逐項核對最新菜單；個別來源可能較舊。來源與日期、外送價差、多人分攤或季節性均附於詳細頁。

料理／型態／時段以公開菜單定位分類。適合場合與兒童友善評級為資料輔助判斷，不是店家承諾。兒童友善只有「適合、普通、不適合」三值；資料不足的店家暫列「普通」，詳細頁註明尚未確認適合兒童。

圖片使用外部原始連結，權利屬原攝影者，未下載、未宣稱取得再發布授權。此版本供本地檢視；正式公開部署應另確認可使用的圖片來源。

## 檔案

- `index.html` / `style.css` / `app.js`：網站。
- `data.js`：網頁讀取的靜態資料。
- `restaurants.json`：可供後續維護的完整資料。
- `maps-research.json` / `routes-research.json`：本次公開店家與路線查閱紀錄。
- `build_data.py`：整理與驗證資料，執行後更新 `data.js` 和 `restaurants.json`。
- `expanded-maps-research.json` / `expanded-routes-research.json` / `expanded-metadata.json`：擴充名單的店家、路線與分類紀錄。
- `expansion-200-maps.json` / `expansion-200-routes.json` / `expansion-200-metadata.json`：新增 150 間的查閱紀錄與分類；全部共 1,000 張照片連結。
- `prepare_public.py`：產生移除精確起點的公開網站檔案。
- `expansion-500-maps.json` / `expansion-500-routes.json` / `expansion-500-metadata.json`：新增 300 間正式名單的研究紀錄與分類；全部共 2,500 張照片連結。
- `classify_expansion.py`：依 Maps 店家類型分類與挑選合格名單；價格、場合及兒童友善推估會註明。
- `home-map.json`：本地使用的出發點。

本版包含使用者提供的精確出發點與導航起點。專案儲存庫：[zero7895/home_nearby_food](https://github.com/zero7895/home_nearby_food)。

手機版已檢查 320、390、430px 寬度：單欄店家卡片、雙欄篩選、44px 以上主要觸控按鈕、橫向照片列與可捲動詳細頁。

步行區間：0–5 分鐘 55 間、超過 5 至 10 分鐘 90 間、超過 10 至 20 分鐘 225 間；另外 130 間超過步行 20 分鐘但符合開車 15 分鐘。全數 50 間均在此次查閱的開車 15 分鐘範圍內。時間不是固定值，可能因交通改變。
