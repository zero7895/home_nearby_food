# 巷口清單 · home_nearby_food

本地預覽網站：以板橋新埔生活圈為中心，整理 Google 步行 20 分鐘內或開車 15 分鐘內的 664 家店。

## 預覽

這是純 HTML、CSS、JavaScript 網頁，不需要安裝套件。可以直接開啟 `index.html`，或使用 Python 靜態伺服器：

```sh
python3 -m http.server 8765 --bind 127.0.0.1
```

瀏覽 `http://127.0.0.1:8765`。店家照片和字型需要網路；照片失效時會顯示提示與 Google Maps 原始頁面入口。

## 功能

- 餐點搜尋、Google 評分／評論數／距離／價格排序。
- 料理國別、餐廳型態、適合時段、場合、兒童友善交叉篩選。
- 七種人均價帶；估算價格範圍與價帶有交集就列入，可能落在多個價帶。
- 每店五張 Google Maps 頁面照片、放大相簿、資料來源與步行／開車導航。
- 每次載入 24 間卡片，搜尋與篩選涵蓋全部 664 間。
- 本機收藏，儲存在瀏覽器 localStorage；沒有登入或外部資料庫。

## UI 名稱約定

以下名稱對應使用者提供的三張畫面截圖，供後續討論介面時使用：

| 名稱 | 對應畫面與範圍 |
| --- | --- |
| **首頁餐廳資訊卡**（也可稱 **首頁卡牌**） | 圖一：首頁店家清單中的一張卡片，包含照片、店名、地址、標籤、簡介、價格及「詳細介紹」等內容。對應 `#cards` 裡的 `.card`。 |
| **隨機卡牌**（也可稱 **隨機頁面卡**） | 圖二：按「正餐」或「點心」後，隨機推薦視窗中三張店家卡片的**其中一張**。對應 `#random-results` 裡的 `.random-card`；整個三張卡片的視窗稱「隨機推薦視窗」。 |
| **詳細資訊卡** | 圖三：按任一卡片的「詳細介紹」後跳出的店家詳細資料視窗，包含照片、交通時間、預算、評論、地址與推薦品項等。對應 `#detail`。 |

卡牌內容的名稱與資料來源：

| 名稱 | 定義 |
| --- | --- |
| **餐廳簡介** | 描述餐廳特色或用餐情境的短句，例如「甜點或烘焙點心，適合下午茶與外帶分享。」或「火鍋主餐，適合午晚餐與朋友聚會。」來源是店家資料的 `description`。首頁卡牌和隨機卡牌都顯示同一家店的這個欄位。 |
| **推薦品項** | 具體餐點名稱的清單，例如「檸檬甜塔、鮭魚青花菜鹹派、奶油可頌」。來源是店家資料的 `dishes`；首頁卡牌有資料時顯示「推薦品項」標題與最多三項；詳細資訊卡顯示此欄位的全部品項，無資料時顯示「推薦品項待補充」。 |

隨機卡牌的餐廳說明文字一律稱「餐廳簡介」，使用與首頁卡牌相同的 `description`，不以「推薦品項」取代。

詳細資訊卡的「人均消費」顯示 `price` 的單一估算區間，例如「NT$150–400」；`priceBands` 僅供首頁預算篩選使用。

## 資料與限制

### 推薦品項補充（2026-10-05）

- 保留原有 17 間店家的推薦品項，另補充 555 間；本次另新增 56 間店家；前輪 631 筆店家中，628 筆已有推薦品項；本轮新增28間、排除埔墘市場後，目前658間中656間已有品項。
- 首頁與詳細資訊卡均讀取同一個 `dishes` 欄位。首頁顯示前三項，詳細資訊卡顯示全部。
- 依現有 Google Maps 研究快照的具體餐點好評、店家菜單／招牌品項、官方網站、分店外送菜單與實訪食記整理。連鎖店使用品牌菜單時，在研究紀錄標示 `scope: brand`，不代表每間分店都供應所有品項。
- `recommended-dishes-research.json` 保留每店品項、來源、查閱日期，以及 Maps 快照檔名與餐點證據。評論語境整理的名稱另記錄 `normalizationNote`，不是宣稱逐字抄自最新菜單。
- `build_data.py` 在分類修正後套用這份推薦品項資料，重建時會保留；原本評分、價格、店址、照片和交通資料不因本次補充而變動。
- 尚有 2 筆待補充：小英越南小吃、陳媽媽家的味道便當店；埔墘市場已因不是單一餐廳而移除。查核狀態記錄於 `recommended-dishes-unresolved.json`。
- 品項是公開資料整理的點餐參考；舊食記、評論與季節水果甜點不保證目前仍供應，實際以店家當日菜單為準。原有店家的其他資料查閱日期仍是 2026-10-04；本次新增店家的店家資訊與交通於 2026-10-05 查核。

原有資料查閱日期為 **2026-10-04**，本次新增 56 間於 **2026-10-05** 複查店家資訊與交通。評分、評論數與店址直接讀取 Google Maps 店家頁面；步行與開車距離和時間直接讀取 Maps 路線，以住家所在社區起點出發，未計出電梯、停車、停車後步行、候餐與排隊時間。不是現場測量或即時營業保證。658 家是不重複收錄名單，並非附近全店普查。

人均為估算預算，依公開食記、菜單或外送價格整理；新補店家部分預算為依定位與公開照片／評論推估，尚未逐項核對最新菜單；個別來源可能較舊。來源與日期、外送價差、多人分攤或季節性均附於詳細頁。

料理／型態／時段以公開菜單定位分類。適合場合與兒童友善評級為資料輔助判斷，不是店家承諾。兒童友善只有「適合、普通、不適合」三值；資料不足的店家暫列「普通」，詳細資訊卡顯示「普通(未確認)」。

圖片使用外部原始連結，權利屬原攝影者，未下載、未宣稱取得再發布授權。此版本供本地檢視；正式公開部署應另確認可使用的圖片來源。

## 檔案

- `index.html` / `style.css` / `app.js`：網站。
- `data.js`：網頁讀取的靜態資料。
- `restaurants.json`：可供後續維護的完整資料。
- `maps-research.json` / `routes-research.json`：本次公開店家與路線查閱紀錄。
- `build_data.py`：整理與驗證資料，執行後更新 `data.js` 和 `restaurants.json`。
- `expanded-maps-research.json` / `expanded-routes-research.json` / `expanded-metadata.json`：擴充名單的店家、路線與分類紀錄。
- `expansion-200-maps.json` / `expansion-200-routes.json` / `expansion-200-metadata.json`：新增 150 間的查閱紀錄與分類；全部共 1,000 張照片連結。
- `prepare_public.py`：產生移除精確起點的公開網站檔案。
- `expansion-500-maps.json` / `expansion-500-routes.json` / `expansion-500-metadata.json`：新增 300 間正式名單的研究紀錄與分類；全部共 2,500 張照片連結。
- `classify_expansion.py`：依 Maps 店家類型分類與挑選合格名單；價格、場合及兒童友善推估會註明。
- `home-map.json`：本地使用的出發點。

本版包含使用者提供的精確出發點與導航起點。專案儲存庫：[zero7895/home_nearby_food](https://github.com/zero7895/home_nearby_food)。

手機版已檢查 320、390、430px 寬度：單欄店家卡片、雙欄篩選、44px 以上主要觸控按鈕、橫向照片列與可捲動詳細頁。

步行區間：0–5 分鐘 59 間、超過 5 至 10 分鐘 92 間、超過 10 至 20 分鐘 251 間；另外 256 間超過步行 20 分鐘但符合開車 15 分鐘。全數 658 間符合步行或開車條件；時間會因交通改變。
