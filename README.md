# 巷口清單 · home_nearby_food

本地預覽網站：以板橋新埔生活圈為中心，整理 Google 步行 15 分鐘內的第一批 14 家店。

## 預覽

這是純 HTML、CSS、JavaScript 網頁，不需要安裝套件。可以直接開啟 `index.html`，或使用 Python 靜態伺服器：

```sh
python3 -m http.server 8765 --bind 127.0.0.1
```

瀏覽 `http://127.0.0.1:8765`。店家照片和字型需要網路；照片失效時會顯示提示與 Google Maps 原始頁面入口。

## 功能

- 餐點搜尋、Google 評分／評論數／距離／價格排序。
- 料理國別、餐廳型態、適合時段、場合、兒童友善與設施交叉篩選。
- 七種人均價帶；估算價格範圍與價帶有交集就列入，可能落在多個價帶。
- 每店五張 Google Maps 頁面照片、放大相簿、資料來源與步行導航。
- 本機收藏，儲存在瀏覽器 localStorage；沒有登入或外部資料庫。

## 資料與限制

資料查閱日期為 **2026-10-04**。評分、評論數與店址直接讀取 Google Maps 店家頁面；步行距離和時間直接讀取 Maps 路線，以住家所在社區起點出發，未計出電梯、候餐與排隊時間。不是現場測量或即時營業保證。14 家是首批名單，並非附近全店普查。

人均為估算預算，依公開食記、菜單或外送價格整理；個別來源可能較舊。來源與日期、外送價差、多人分攤或季節性均附於詳細頁。

料理／型態／時段以公開菜單定位分類。適合場合與兒童友善評級為資料輔助判斷，不是店家承諾。兒童設施沒有證據就記錄「未查證」，不表示沒有；有第三方資料的設施明確標示證據層級。

圖片使用外部原始連結，權利屬原攝影者，未下載、未宣稱取得再發布授權。此版本供本地檢視；正式公開部署應另確認可使用的圖片來源。

## 檔案

- `index.html` / `style.css` / `app.js`：網站。
- `data.js`：網頁讀取的靜態資料。
- `restaurants.json`：可供後續維護的完整資料。
- `maps-research.json` / `routes-research.json`：本次公開店家與路線查閱紀錄。
- `build_data.py`：整理與驗證資料，執行後更新 `data.js` 和 `restaurants.json`。
- `home-map.json`：本地使用的出發點。

本版包含使用者提供的精確出發點與導航起點。專案儲存庫：[zero7895/home_nearby_food](https://github.com/zero7895/home_nearby_food)。
